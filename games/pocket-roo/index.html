Pocket Roo

화면 구석에 띄워두는 작은 캥거루 복싱 링

Mac용은 Apple Silicon(M1 이상) Mac에서만 실행됩니다. Intel Mac에서는 실행되지 않습니다.

코드를 짜다가, 문서를 쓰다가 잠깐 손이 비면 캥거루로 펀치와 킥을 몇 번 날리면 됩니다. 창은 다른 창 위에 떠 있지만 480×300 크기라서 하던 일을 가리지 않습니다. CPU 캥거루와 겨루는 스파링, 마음껏 때리는 샌드백 모드가 있습니다.

PC에서만 다운로드가 가능합니다.

A D좌우로 움직입니다
W꼬리로 바닥을 차고 점프
S누르고 있는 동안 앉기
J K펀치 / 킥
L누르고 있는 동안 가드 (스파링)
Space뒤로 피하기 (스파링)
T자유 연습 / 30초 타임 어택 바꾸기 (샌드백)
Esc멈추고 메뉴 열기

macOS

Apple Silicon(M1 이상) Mac에서 실행됩니다. 내려받기 페이지에서 mac-arm64.dmg 파일을 받습니다.

  1. .dmg를 열고 Pocket Roo를 응용 프로그램 폴더로 끌어다 놓습니다.
  2. 앱을 실행합니다. 아직 Apple 공증을 받지 않은 앱이라 처음에는 "확인되지 않은 개발자" 경고가 뜨고 열리지 않습니다.
  3. 시스템 설정 → 개인정보 보호 및 보안으로 가서 아래쪽의 그래도 열기를 누릅니다. 한 번만 하면 됩니다.
  4. 화면 오른쪽 아래에 게임 창이 뜹니다. 모드를 고르고 Enter를 누르면 시작합니다.

3번이 안 되면 터미널에서 아래 명령을 한 번 실행해도 됩니다.

xattr -dr com.apple.quarantine "/Applications/Pocket Roo.app"

Windows

Windows 10 이상에서 실행됩니다. 내려받기 페이지에서 windows-setup.exe 파일을 받습니다. 설치 파일 하나로 일반 PC(x64)와 ARM PC를 모두 지원합니다.

  1. 받은 설치 파일을 실행합니다.
  2. 아직 코드 서명을 하지 않은 앱이라 "Windows의 PC 보호" 창이 뜹니다. 추가 정보를 누른 뒤 실행을 누릅니다.
  3. 관리자 권한 없이 내 계정에만 설치되고, 끝나면 바로 게임이 실행됩니다. 바탕화면과 시작 메뉴에 바로가기가 생깁니다.
  4. 지울 때는 설정 → 앱 → 설치된 앱에서 Pocket Roo를 제거합니다.

업데이트

앱이 스스로 업데이트하지는 않습니다. 새 버전이 나오면 다시 받아 같은 방법으로 설치하면 됩니다. 저장하는 데이터가 없어서 덮어써도 잃는 것은 없습니다.

패치 노트

1.0.2

  • 투명 모드를 넣었습니다. O 키나 위쪽의 '100%' 버튼으로 창을 100% → 60% → 30%로 흐리게 합니다.
  • 배경을 끌 수 있습니다. B 키나 'BG' 버튼을 누르면 벽·관중·조명이 사라지고 링과 캥거루만 바탕화면 위에 남습니다.
  • 두 설정 모두 다음에 켤 때도 그대로입니다. Esc 메뉴에서도 바꿀 수 있습니다.
  • CPU가 조금 강해졌습니다. 반응이 빨라지고, 더 자주 공격하고, 더 잘 막고, 점프를 어퍼컷으로 더 자주 받아칩니다. EASY / NORMAL / HARD 모두 올랐습니다.

1.0.1

  • 앱 이름을 Corner Kangaroo에서 Pocket Roo로 바꿨습니다.
  • 픽셀 캥거루 앱 아이콘을 넣었습니다.
  • Mac에서 1.0.0을 쓰던 경우 응용 프로그램 폴더에 Corner Kangaroo가 따로 남으니 지우면 됩니다. Windows 설치 파일은 이전 버전을 알아서 바꿉니다.

1.0.0

  • 첫 버전입니다.
  • 스파링: CPU와 1:1, 펀치·킥·가드·피하기, EASY / NORMAL / HARD 난이도
  • 꼬리 점프, 앉기, 상단·중단·하단·공중 높이 구분과 앉아 가드
  • 로우 잽, 꼬리 스윕, 어퍼컷, 파워 스트레이트, 꼬리 드롭킥, 점프 공격과 기술표
  • 스파링에서 이기면 왕관
  • 샌드백: 자유 연습과 30초 타임 어택, 콤보와 점수 기록
  • 항상 위 표시, 창 이동, 일시정지와 재시작
  • Mac, Windows 지원
