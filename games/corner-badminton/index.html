Corner Badminton

화면 구석에 띄워두는 작은 배드민턴 체육관

Mac용은 Apple Silicon(M1 이상) Mac에서만 실행됩니다. Intel Mac에서는 실행되지 않습니다.

코드를 짜다가, 문서를 쓰다가 잠깐 손이 비면 셔틀콕을 한 번 넘기면 됩니다. 창은 다른 창 위에 떠 있지만 480×300 크기라서 하던 일을 가리지 않습니다. 21점을 먼저 내면 이깁니다.

PC에서만 다운로드가 가능합니다.

A D좌우로 움직입니다
W점프합니다
Space라켓을 휘두릅니다. 서브도 Space입니다
Esc잠깐 멈추고 메뉴를 엽니다
O창을 흐리게 합니다 (100% → 60% → 30%)
B배경을 끄고 코트, 네트, 캥거루만 남깁니다

macOS

Apple Silicon(M1 이상) Mac에서 실행됩니다. 위의 내려받기 버튼으로 mac-arm64.dmg 파일을 받습니다.

  1. .dmg를 열고 Corner Badminton을 응용 프로그램 폴더로 끌어다 놓습니다.
  2. 앱을 실행합니다. 아직 Apple 공증을 받지 않은 앱이라 처음에는 "확인되지 않은 개발자" 경고가 뜨고 열리지 않습니다.
  3. 시스템 설정 → 개인정보 보호 및 보안으로 가서 아래쪽의 그래도 열기를 누릅니다. 한 번만 하면 됩니다.
  4. 화면 오른쪽 아래에 게임 창이 뜹니다. 바로 Space를 눌러 서브하면 됩니다.
  5. 다른 창 위에 띄워두기 싫으면 위쪽의 PIN 버튼을 눌러 끕니다.
  6. 일하는 중이라 티 나지 않게 하려면 O 키나 위쪽의 100% 버튼으로 창을 흐리게 합니다. 누를 때마다 100% → 60% → 30%로 바뀝니다. B 키나 BG 버튼으로 배경을 끄면 코트, 네트, 캥거루만 바탕화면 위에 남습니다. 둘 다 다음에 켤 때도 그대로입니다.
  7. 끌 때는 위쪽의 X 버튼을 누르거나 Esc 메뉴에서 QUIT을 고릅니다.

3번이 안 되면 터미널에서 아래 명령을 한 번 실행해도 됩니다.

xattr -dr com.apple.quarantine "/Applications/Corner Badminton.app"

Windows

Windows 10 이상에서 실행됩니다. 위의 내려받기 버튼으로 windows-setup.exe 파일을 받습니다. 설치 파일 하나로 일반 PC(x64)와 ARM PC를 모두 지원하고, 알아서 맞는 버전을 설치합니다.

  1. 받은 설치 파일을 실행합니다.
  2. 아직 코드 서명을 하지 않은 앱이라 "Windows의 PC 보호" 창이 뜹니다. 추가 정보를 누른 뒤 실행을 누릅니다.
  3. 관리자 권한 없이 내 계정에만 설치되고, 끝나면 바로 게임이 실행됩니다. 바탕화면과 시작 메뉴에 바로가기가 생깁니다.
  4. 화면 오른쪽 아래에 게임 창이 뜹니다. 바로 Space를 눌러 서브하면 됩니다.
  5. 다른 창 위에 띄워두기 싫으면 위쪽의 PIN 버튼을 눌러 끕니다.
  6. 일하는 중이라 티 나지 않게 하려면 O 키나 위쪽의 100% 버튼으로 창을 흐리게 합니다. 누를 때마다 100% → 60% → 30%로 바뀝니다. B 키나 BG 버튼으로 배경을 끄면 코트, 네트, 캥거루만 바탕화면 위에 남습니다. 둘 다 다음에 켤 때도 그대로입니다.
  7. 지울 때는 설정 → 앱 → 설치된 앱에서 Corner Badminton을 제거합니다.

업데이트

앱이 스스로 업데이트하지는 않습니다. 새 버전이 나오면 위의 내려받기 버튼으로 다시 받아 위와 같이 설치하면 됩니다. 저장하는 데이터가 없어서 덮어써도 잃는 것은 없습니다.

  • macOS: 새 .dmg를 열고 응용 프로그램 폴더로 끌어다 놓은 뒤, 같은 이름의 앱이 있다고 나오면 대치를 누릅니다. 새로 받은 앱이라 처음 실행할 때 "그래도 열기"나 xattr 명령을 다시 해야 할 수 있습니다.
  • Windows: 게임을 끈 다음 새 설치 파일을 실행하면 기존 버전 위에 덮어써집니다. 먼저 지울 필요는 없습니다.

패치 노트

1.0.4

  • 투명 모드를 넣었습니다. O 키나 위쪽의 '100%' 버튼으로 창을 100% → 60% → 30%로 흐리게 합니다.
  • 배경을 끌 수 있습니다. B 키나 'BG' 버튼을 누르면 벽과 조명이 사라지고 코트, 네트, 캥거루만 바탕화면 위에 남습니다.
  • 두 설정 모두 다음에 켤 때도 그대로입니다. Esc 메뉴에서도 바꿀 수 있습니다.

1.0.3

  • 앱 아이콘을 넣었습니다.
  • 게임 내용은 1.0.2와 같습니다.

1.0.2

  • CPU를 더 약하게 했습니다. 특히 기본 난이도인 NORMAL이 많이 쉬워져서, 이전 EASY와 비슷한 수준이 됐습니다.
  • CPU가 더 느리게 움직이고, 반응이 늦고, 낙하지점을 더 자주 잘못 읽습니다. 밖으로 나갈 공을 받아 치는 일도 늘었습니다.
  • HARD는 조금만 약해졌습니다.

1.0.1

  • 라켓을 키웠습니다. 라켓이 더 크게 보이고, 공이 맞는 범위도 넓어져서 셔틀콕을 받아치기 쉬워졌습니다.
  • 라켓 가장자리에 맞아 엉뚱한 곳으로 가거나 네트에 걸리는 일이 줄었습니다.
  • CPU 라켓도 같이 커지는 만큼 CPU의 실수를 조금 늘려서, CPU가 더 강해지지 않게 맞췄습니다.

1.0.0

  • 첫 버전입니다.
  • CPU와 1:1 단일 게임, 21점제
  • 드롭·클리어·스매시, EASY / NORMAL / HARD 난이도
  • 항상 위 표시, 창 이동, 일시정지와 재시작
  • Mac, Windows 지원
